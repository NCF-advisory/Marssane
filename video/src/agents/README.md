# Video equipe agents

Source du montage blanc importe depuis le projet Remotion du 8 septembre 2026.
La V12 conserve le montage V11, son "Voici" noir en 64 px et sa pause initiale
d'une seconde. Les noms affiches sont Jacques et Camille ; les noms des fichiers
de portraits restent inchanges. Le logo utilise le composant MarssaneLogo du
sous-projet video, avec les couleurs et proportions du site.

Depuis `video` : `node scripts/render-equipe.mjs`.
Ajouter `--preview` pour ne produire que les images de controle temporaires.
Le script exporte le MP4 H.264 1920x1080 a 60 fps et son poster dans `public/video`
du site. Aucun changement des videos utilisees par les pages de formation.
